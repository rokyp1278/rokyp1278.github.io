Drone AI Agents

StatusDirection I am moving toward — no results yet QuestionCan an onboard agent decide how far to trust its own perception?

Why this follows

Everything I have worked on so far ends at the same place: a system is fed sensor data it cannot fully verify, and something outside the vehicle has to decide what to do about it. The spoofing defense detects and recovers, but a human designed the detector, chose its threshold, and set what happens when it fires. The vehicle itself is not reasoning about any of it.

That is the gap I want to work in. An agent flying a real mission meets conditions nobody enumerated in advance — a sensor that degrades instead of failing, a reference that is available but wrong, a situation where continuing and aborting are both defensible. Handling that well is a decision-making problem, not only a detection problem.

What I want to build toward

  • Perception the agent can question. An estimate that arrives with a defensible statement of how much it should be believed, rather than a number presented as fact.
  • Graceful degradation as a policy. Choosing to slow down, hold, return, or hand back control — and doing it because the evidence supports it, not because a threshold tripped.
  • Decisions that can be audited. If an agent aborts a mission, the reason should be reconstructable afterwards. For anything flying in a defense context this matters as much as the decision itself.
  • Coordination without a single point of trust. Extending this from one vehicle to a swarm, where agents have to agree while some of them may be wrong.

Honest status

This is a direction, not a result. I have no publications here yet. It is on this page because it is where the work I have done points, and because it is what I want to spend graduate study on: the same trust question I have been chasing in sensing, moved up into the decision layer.

Swarm Robustness (HW / SW)

StatusOngoing direction, grown out of the spoofing work ScopeSensing hardware and the software that fuses, agrees, and decides

The question

A swarm defense built on trusted references only works while those references are trustworthy. That assumption is comfortable on paper and fragile in the field: sensors degrade, links drop, hardware fails, and a member can be compromised outright. The question this direction asks is what the swarm should do once part of it can no longer be believed — not whether it can detect the problem, but whether it can keep flying correctly through it.

The interest is deliberately split across two layers. Hardware decides what the swarm can measure at all and how it fails when a sensor drifts rather than dies. Software decides how those measurements are fused, how members reach agreement, and how much a single bad input can move the collective answer.

What the spoofing work already established

This is not a fresh start. The anchor-based defense turned out to have failure modes worth studying on their own terms, and characterizing them is what made the direction concrete:

  • Correlated failure is the hard case. Independent anchor faults are manageable; anchors failing in a common mode collapse detection, because the very correlation that the consensus relies on is what the failure destroys.
  • Trust dilutes with scale. A fixed number of references spread across a larger swarm leaves the far members with progressively weaker evidence, so recovery error grows with swarm size rather than staying flat.
  • Byzantine members need outvoting, not averaging. Robust fitting holds up to a bounded fraction of lying anchors, and degrades sharply past it — the boundary is where the interesting engineering sits.
  • Some faults are genuinely ambiguous. Slow drift and a slow attack can produce the same observable, and separating them needs either a clean reference epoch or a second, independent sensing modality.

Where it goes

The direction I want to push is toward swarms that carry heterogeneous, independently-failing sensing rather than one shared modality, so that a common-mode failure has somewhere to be caught. Alongside that: agreement protocols whose degradation is graceful and predictable as members drop out or turn hostile, and an honest account of how much reference infrastructure a swarm of a given size actually needs.

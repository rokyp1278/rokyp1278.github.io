Autonomous Landmine-Detection Robot

Year2026 ContextCapstone Design Project, Defense Creative Engineering Design RoleTeam leader (team of 4) StackROS 2 Jazzy · Clearpath Jackal UGV · NVIDIA Jetson

The mission

The robot has to survey terrain it has never seen, find the mines hidden in it, and then go back to the place where the mines are densest so that a demolition team can be sent to one spot instead of many. AprilTags stand in for the mines. Nothing about the map is known in advance, so exploration, mapping, detection, and target selection all have to happen in one continuous run.

Computation is split across two machines. A mini-PC carries SLAM, planning, and navigation; an NVIDIA Jetson carries perception. Keeping detection off the planning machine means the vision model never competes with the control loop for CPU.

Navigation written from scratch

The advisor set one constraint that shaped the whole project: no Nav2. The navigation stack had to be written rather than configured, which meant building each layer and understanding why it behaves the way it does.

  • Mapping — 2D graph SLAM through slam_toolbox, building the occupancy grid the planner consumes.
  • Exploration — breadth-first frontier detection over that grid, selecting the next boundary between known and unknown space to push into.
  • Planning — A* with an octile heuristic, run over a self-implemented configuration-space inflation cost map so the path keeps clearance from obstacles rather than grazing them.
  • Control — pure pursuit tracking to follow the planned path.

From detections to demolition targets

A single frame that says "there is a tag here" is not a target. Turning detections into something a demolition team can act on takes three more steps.

  • Detection — YOLOv8n trained on a self-generated AprilTag dataset, running on the Jetson, combined with AprilTag recognition for identity.
  • Localization — each tag is placed into the map frame via solvePnP and tf2, with per-ID median accumulation so that repeated sightings of the same tag converge instead of scattering.
  • Clustering — DBSCAN with a 2.0 m radius groups the accumulated positions into hotspots, and the robot drives to each hotspot centroid in order of tag density.

Platform

  • Base — Clearpath Jackal UGV, mini-PC plus NVIDIA Jetson
  • Sensors — Livox MID360 LiDAR, dual RealSense depth cameras
  • Middleware — ROS 2 Jazzy
